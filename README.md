## 📖 About

Rowan's Weather HQ is a single-file interactive web page covering everything a young weather enthusiast could want to know about the atmosphere, storms, and the science behind what happens in the sky. It was built for someone living in Kansas City — right where all kinds of extreme weather collide — and designed to make learning feel like playing.

The page is part of **Rowan's Storm Collection**, a set of weather-themed educational projects sharing the same stormy dark-sky aesthetic: animated rain, lightning flashes, twinkling stars, and glowing blue accents.

---

## ✨ Features

- **9 fully interactive sections** navigated by tab buttons
- **Weather Mixer Lab** — combine two weather types and discover what they make (18 named combinations to find!)
- **Live temperature converter** — Fahrenheit ↔ Celsius with a color gradient bar and fun fact messages
- **Sky Painter canvas** — stamp 28 weather emojis in 4 sizes to build your own weather scene
- **Expandable cards** throughout — tap to reveal hidden science and bonus details
- **Animated storm background** — rain, lightning flashes, and twinkling stars
- **Zero dependencies** — pure HTML, CSS, and vanilla JavaScript in one file
- **Mobile friendly** — full touch support, responsive layout
- **Dark storm-sky theme** — blue accent palette matching Rowan's other projects

## 🚀 How to Use

No installation. No build step. No server required.

1. Download `rowan-weather-hq.html`
2. Open it in any modern web browser (Chrome, Firefox, Safari, Edge)
3. Start exploring!

```bash
# Or clone the whole repo
git clone https://github.com/your-username/rowans-weather-hq.git
cd rowans-weather-hq
open rowan-weather-hq.html
```

## 📍 A Note on Kansas City

Kansas City, Missouri sits at the edge of Tornado Alley where cold air from Canada and warm humid air from the Gulf of Mexico collide — making it one of the most weather-varied cities in the US. KC experiences:

- Severe thunderstorms and tornadoes in spring
- Oppressive heat and humidity in summer  
- Ice storms and blizzards in winter
- And everything in between

This project was built with that local context woven throughout — the temperature tool references KC summers, the records section includes nearby storms, and the safety section reflects real KC weather risks.
